## 一句话概括

用 30 部完整电影离线构建一张"社会因果图"（谁信了什么、谁想干什么、哪一步导致了哪一步），评测时把这张图藏起来，只给模型关键帧加剧本片段，让它沿分层问题树自己走一条推理路径；结果发现前沿模型存在两个系统性缺陷——**"选择题陷阱"**（单选常 >90%，换成多选就掉到 26%–70%）和**"生成—判别鸿沟"**（选得对，讲不出理由，开放式得分普遍低于 0.7 阈值）。

## 为什么今天推荐它（与三个关键词的对应）

- **LLM 心智推理**：这是本文的正题。作者的主张是：现有 ToM 基准大多是"实验室式"的短故事，考的是"字面 ToM"（在简单情境里预测行为），而不是真实交互所需的"功能性 ToM"。本文把评测搬到完整长度的电影上，让心理状态必须在数十个场景的因果链中被追踪。
- **ToM**：论文对 ToM 的操作化很值得借鉴——不直接问"他在想什么"，而是先离线标注信念、欲望、意图与因果链接，再让问题树沿"社会因果边"向下生长。深度 1/2/3 分别对应 30、60、90 分钟量级的上下文依赖（正文 §3.2、表 3），这是把"长程"变成可度量变量的少见做法。
- **GRPO**：本文本身**不是**训练工作，没有用 GRPO，也没有 RL 微调——它是纯评测基准。但它恰好提供了 GRPO 最缺的东西：**可验证的过程奖励信号**。其"因果链保真度（CCF）"给出逐步推理的准确率与平均分、"反事实恢复分数（CRS）"给出在假设前提被改写后是否还能自洽推理，二者都可以直接当作 RL 的稠密奖励（而不是只看最终答案对错）；论文报告的"多选崩塌"与"解释退化"也正是 GRPO 类训练最容易过拟合掉的两种失效模式，可作对照实验的靶子。

## 核心贡献

1. **基准**：MovieGraph-ToM，30 部完整电影、48,406 个经校验的 ToM 节点、1,614 个情节节点、2,282 条因果链接，派生约 65,600 道题（开放式 ~31.5k、单选 ~23.6k、多选 ~10.4k），覆盖行为理解、ToM、复杂沟通、情绪理解、社会规范、社会偏见六个一级维度。
2. **方法**："脚手架—探针"（scaffold-and-probe）范式——离线建金标准社会因果图，评测时模型无权访问，只能从原始多模态输入推理。这把"推理结构"与"模型输入"解耦，既强制真实推断，也缓解从预训练记忆里走捷径。
3. **协议**：两阶段评估协议（算法 1）。阶段一让模型自由走树，量其自发推理；阶段二把所有未访问分支改写成反事实前提（"假设上一题答案是 X……"）强制探索，量其逻辑稳健性。由此把"表现"与"稳健性"分开。
4. **指标**：推理深度分数（RDS）、因果链保真度（CCF）、反事实恢复分数（CRS）三个新指标，配合"每部电影 5 张关键帧 + 剧本片段"的轻量多模态输入。
5. **发现**：定位了"选择题陷阱"与"生成—判别鸿沟"两种失效模式，并给出一个反直觉的正面结论——反事实推理能力普遍较强（CRS 0.83–0.92），说明存在一种可与事实记忆解耦的逻辑官能。

## 主要结果（原文口径）

- 总榜：gemini-2.5-pro 最强，总体准确率 **92.0%**、总分 **0.797**，且在五个一级类别上全部第一（行为 91.8/0.775、ToM 92.9/0.832、情绪 93.3/0.743、沟通 89.6/0.775、规范 94.6/0.851）。第二梯队 gpt-4.1（89.8%）、gemini-2.5-flash（89.4%）、mistral-small-3.2-24b（88.2%）。开源的 llava-onevision-qwen2-7b 垫底（75.1%）。
- **选择题陷阱**：单选 → 多选断崖式下跌。gpt-4o-mini 93.8% → **35.4%**，llava-onevision-qwen2-7b 84.6% → **26.9%**（接近随机），最强的 gemini-2.5-pro 也从 96.4% → **70.8%**。
- **生成—判别鸿沟**：开放式题无一模型越过 0.7 分阈值，最好的是 gpt-4.1（**0.675**）与 gemini-2.5-pro（**0.674**），llava 仅 0.622。
- **深度不是线性杀手**：准确率在深度 2 略有下滑、深度 3 反而回升（如 gemini-2.5-pro 90.1 → 90.1 → 93.3），但**解释质量**持续下降（0.892 → 0.792 → 0.760），作者据此推断模型在"跳向结论"而非忠实建模中间因果步。
- **反事实稳健性**：CRS 普遍 0.83–0.92，gemini-2.5-pro 最高 0.918，连 llava 也有 0.828——这是全文唯一的乐观信号。
- 人类评测、指标定义与完整模型清单在正文中指向"附录"，但 9 页正式版不含附录（见译文"译注"第 6 条）。

## 阅读建议

- 先读 §1 引言 + §3.1 流水线（图 1），把"社会因果图 → 问题树 → 关键帧蒙太奇"这条链路看懂，后面的指标才有意义。
- §4.1 与算法 1 是全文最"可搬运"的部分：两阶段协议与 CRS 的设计几乎可以直接移植到别的长程推理基准。
- 只看数字的话：表 4（十模型 × 六类别）、表 5（格式/类型/深度切片）、表 6（RDS/CCF/CRS）；表 5 的列结构在 PDF 里有排版歧义，译文已按可自洽的方式还原并在"译注"第 4 条说明。
- 若关心如何把本文变成训练信号：重点看 CCF 的"每深度准确率 + 平均分"双指标，它是天然的稠密奖励；CRS 则可作为"抗前提扰动"的正则项。
- 注意局限：开放式题的评分是 Qwen3-30B-A3B（70%）+ ROUGE-L（30%）的混合分，作者自己也承认 LLM 评判器可能引入偏差；跨模型比较时这层噪声不能忽略。
